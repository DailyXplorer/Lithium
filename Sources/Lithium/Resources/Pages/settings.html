Extensions

Extensions from the Chrome Web Store, run by the WebKit engine itself. Click Add to Chrome on an extension’s page in the store: Lithium asks first, then adds it.

Most extensions work. Some rely on parts of Chrome that WebKit doesn’t have.

Features

Tidy tab titles
Shortens long tab titles as pages load, like “WebKit project” instead of the full GitHub description. Hover a tab to see its original title. Names you give tabs always win.
Summarize pages
Adds a sparkle button to the toolbar that sums up the page in a sentence and a few key points, in your language. Select a passage first to summarize only that. Runs only when you click it.
Summary language
Summaries are written in this language, whatever the page’s own.

Site Permissions

Sites ask the first time they need your camera, microphone or location. Your answers live here.
