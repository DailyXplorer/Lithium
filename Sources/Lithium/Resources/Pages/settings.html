Other apps
For any app that starts an MCP server as a command.
Details

Agents run lithium-mcp, which reads the token from Lithium when it connects, so their settings never hold it. If Lithium isn’t open, lithium-mcp opens it in the background, without a window.

Only apps on this Mac can connect, with the token in ~/Library/Application Support/Lithium/Agent/endpoint.json, which only your account can read. Turning access off deletes it; turning it on again makes a new token.
