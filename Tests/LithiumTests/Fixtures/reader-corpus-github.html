lithium-cells

Paragraph 01: lithium-cells models the life of a battery cell in Swift, from the coating line to the last charge, so that you can test a pack's software against cells that age, swell and fail the way real ones do. Each model is fitted to months of measurements from a test lab.

Getting started

Paragraph 02: add the package to your manifest's dependencies, then to the target that runs your pack's tests. It has no dependencies of its own and builds on macOS, Linux and Windows with any Swift 6 toolchain.

.package(url: "https://github.com/example/lithium-cells", from: "2.0.0")

Paragraph 03: a cell starts fresh, at the capacity you give it, and loses some of it with every cycle, faster when it is charged hot or quickly, slower when it rests at half charge, as the measurements in the docs folder show. Every model also has a seed, so a failing test fails the same way twice.

Ageing a cell

Paragraph 04: call age(cycles:temperature:) to move a cell through time. It returns the capacity left and the internal resistance, which rises as the layer on the anode thickens, the way formation predicted it would.

let cell = Cell(chemistry: .lfp, capacity: 280)
let aged = cell.age(cycles: 3000, temperature: 35)

Paragraph 05: contributions are welcome. Open an issue first for anything larger than a fix, so that we can agree on the model before you spend a weekend on it, and run the whole test suite before you open a pull request. New chemistries need measurements to fit, not just a guess at the curve.
